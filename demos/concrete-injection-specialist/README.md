# Concrete Injection Specialist — website concept

This is a standalone website, separate from Maven. All website files are in `dist/`.

## GitHub upload
Upload the CONTENTS of `dist/` to the root of your new repository (index.html, styles.css, app.js, and assets/).
For GitHub Pages, choose Settings → Pages → Deploy from a branch → main → / (root).
No build command or installation is needed. You can also connect the repository to a static hosting provider.

## Before launch
- The inquiry form is a clearly labeled preview. It does NOT send or store leads. Connect a secure form service or server endpoint, choose the recipient, add the appropriate privacy notice, and test delivery before enabling live submission.
- Confirm the company name, address, phone, actual services, and all copy with the company.
- The photographs/video are illustrative stock, not company work. Sources are in SOURCES.md and the on-page image credits.
- Remove the concept label and robots noindex tag only when the client approves the public site.
- Google Fonts are loaded externally. Consider self-hosting fonts for launch.

Includes responsive navigation, reduced-motion support, a pause control for the video, infographic sections, inquiry form layout, and working phone/directions links.
