# Philadelphia Junk Removal Demo

Static demo website built from the verified lead information supplied for this test.

## Files
- `index.html` - complete homepage
- `styles.css` - responsive styling
- `script.js` - mobile navigation and year
- `favicon.svg` - site favicon

## Deploying to GitHub + Cloudflare Pages
1. Create a GitHub repository and upload these files.
2. In Cloudflare Pages, connect the repository.
3. Framework preset: None / Static HTML.
4. Build command: leave blank.
5. Build output directory: `/` (the repository root).
6. Deploy.
7. Attach a demo domain/subdomain.
